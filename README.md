# 🦸‍♂️ Superhero Dispatch Network (SDN)
Program manajemen perusahaan dispatch superhero berbasis C++.

## 📖 Deskripsi Program
**Superhero Dispatch Network (SDN)** adalah perusahaan dispatch superhero yang terinspirasi dari game *Dispatch* karya Adhoc Studio. SDN memiliki cabang di seluruh dunia dan bertugas melayani pelanggan yang membutuhkan bantuan darurat dengan mengirimkan superhero sesuai kemampuan dan kebutuhan misi.

Program ini dibuat menggunakan **bahasa C++** dengan sistem **CRUD (Create, Read, Update, Delete)** untuk mengelola data superhero, dispatcher, dan sistem dispatch superhero.

---

- Multi User Login
- CRUD Data

- JSON Storage

---

## 🏢 Hierarki Peran dalam SDN
Terdapat 3 peran utama dalam sistem:

### 👑 Head of SDN
Sebagai manajer utama perusahaan yang bertanggung jawab mengelola seluruh data superhero dan dispatcher.

### 📞 Dispatcher
Bertugas mengatur, memilih, dan mengirim superhero ke misi darurat secara cepat dan efektif.

### 🦸 Superhero
Aset utama perusahaan yang memiliki kekuatan unik dan statistik tertentu untuk membantu menyelesaikan misi.

---

## 📍 Fitur Program

### 👑 Head of SDN (Admin)
🔐 Login Head of SDN

**Username:** `admin`  
**Password:** `admin1234`

Head of SDN dapat:

- Login admin
- Rekrutmen dan registrasi superhero
- Melihat seluruh data superhero di billboard
- Meng-update biografi superhero
- Meng-update statistik superhero
- Memecat superhero
- Membuat akun dispatcher
- Menghapus akun dispatcher
- Sorting data superhero
- Searching data superhero

---

### 📞 Dispatcher
Dispatcher dapat:

- Login akun dispatcher
- Menambahkan superhero ke dalam list dispatch
- Mengirim superhero ke misi
- Menampilkan daftar superhero yang telah ditambahkan
- Upgrade statistik hero
- Menghapus superhero dari list
- Mengelola data dispatch superhero

---

### 🦸 Superhero
Superhero berfungsi sebagai:

- Penyedia data kekuatan hero
- Penyedia status ketersediaan hero
- Aset utama dalam dispatch misi
- Pemilik statistik performa yang dapat diperbarui setelah misi selesai
